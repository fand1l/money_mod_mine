# colors.txt containing only our 3 countries, every vanilla country would lose
# its map color. That is why this mod does NOT ship a colors.txt.
#
# DO THIS ONCE (details in GUIDE.md, step 3):
#   1. Open the GAME's install folder, e.g.
#      C:\Program Files (x86)\Steam\steamapps\common\Hearts of Iron IV
#   2. Copy the file   common\countries\colors.txt
#      into THE MOD at  <mod folder>\common\countries\colors.txt
#      (next to Nesterivtsi.txt).
#   3. Open the copied file in your text editor, scroll to the very bottom,
#      and paste the block below. Save. Done.
# ==============================================================================
